\subsection{JavaScriptによる時間制御処理}\label{subsec:javascript}
 ソースコード\ref{repeatSeq}は、ソースコード\ref{animation_fs}内のアニメーション生成における時間制御を行う処理を実装したコードである。
 \begin{lstlisting}[caption={時間制御処理（fsファイル）},label={repeatSeq},breaklines=true,breakatwhitespace=false]
        wrJS.Write "function repeatSeq(fn, interval, Nt, onComplete)"
        wrJS.Write "{"
        wrJS.Write "    let t = 0;"
        wrJS.Write "    function run()"
        wrJS.Write "    {"
        wrJS.Write "        if (t < Nt)"
        wrJS.Write "        {"
        wrJS.Write "            fn(t);"
        wrJS.Write "            t++;"
        wrJS.Write "            setTimeout(run, interval);"
        wrJS.Write "        }"
        wrJS.Write "        else"
        wrJS.Write "        {"
        wrJS.Write "            onComplete();"
        wrJS.Write "        }"
        wrJS.Write "    }"
        wrJS.Write "    run();"
        wrJS.Write "}"
\end{lstlisting}
1行目において、アニメーション生成における時間制御処理を行うrepeatSeq関数を定義している。本関数は四つの引数を取る。
第一引数は、各フレームごとに実行される処理を表す関数であり、フレーム番号tを引数として受け取る。第二引数は、処理の実行時間をミリ秒単位で指定するものであり、アニメーションの時間的な間隔を制御する。
第三引数は、処理を繰り返す回数を表し、アニメーションの総フレーム数に相当する。第四引数は、すべての繰り返し処理が終了した後に実行される空の関数である。
関数内部では、変数tを用いてフレーム番号を管理している。内部関数runにおいて、tがNt未満である場合は、fn(t)を実行する。その後setTimeoutを用いて一定時間後に再び呼び出すことで、処理を繰り返している。
tがNtに達した時点で繰り返し処理を終了し、onCompleteを実行することで、アニメーションを終了する。

\subsection{時間に応じた変形・移動}
ソースコード\ref{line_times}では、直線の始点および終点の座標を時間の関数として定義している。
 \begin{lstlisting}[caption={時間に応じた移動（fsxファイル）},label={line_times},breaklines=true,breakatwhitespace=false]
f.seq {FrameTime=30; FrameNumber=1000} <| fun _ ->
        line0.P {Start = {X = fun _ -> Dbl_e 200
                          Y = fun t -> 240+100*asm.sin(-2.0*Math.PI*t/100)}
                 End = {X = fun _ -> Dbl_e 400

x座標はそれぞれ一定値（200,400）に固定されており、直線は水平方向に配置されている。一方、y座標は時間tに依存する正弦関数として定義されており、直線の両端が周期的に上下方向へ振動するアニメーションになっている。
また、f.seqはアニメーションにおける時間進行を制御する関数であり、FrameTime=30、FrameNumber=1000の指定により、30ms間隔で1000フレームのアニメーションを生成している。

なお、詳細は割愛するが、同様の構造を用いることで、数式が時間とともに移動するアニメーションも実現可能である。

\section{アニメーション図説フレームワークの機能}
これまでの節で説明してきたアニメーションに加えて、繰り返し構文を用いることで、波形アニメーションのように多数の図形から構成される表現を容易に実現可能である。
また、本研究で提案するアニメーション図説フレームワークでは、音声の再生や字幕、キャラクターを表示といった表現も可能である。
