ソースコード\ref{animation_fs}では、htmlクラスに静的メンバ関数として描画領域生成処理を定義している。本関数は五つの引数を取る。
第一引数は、出力ファイルの保存先を指定する。第二引数は出力するファイル名を指定する。
第三引数はアニメーション描画領域の設定を行う。第四引数はアニメーション描画領域の描画位置を指定する。第五引数はアニメーションボタンの位置を指定する。
\par
4～5行目では、アニメーションの時間制御を行うJavaScriptファイルを自動生成する処理を実装している。
6～8行目では、アニメーションの描画領域を設定するHTMLファイルを自動生成する処理を実装している。これらの処理の詳細は、\ref{subsec:javascript}節および\ref{subsec:html}節において述べる。

\subsection{JavaScriptによる時間制御処理}\label{subsec:javascript}
 ソースコード\ref{repeatSeq}は、ソースコード\ref{animation_fs}内のアニメーション生成における時間制御を行う処理を実装したコードである。
 \begin{lstlisting}[caption={時間制御処理},label={repeatSeq},breaklines=true,breakatwhitespace=false]
        wrJS.Write "    function run()"
        wrJS.Write "    {"
        wrJS.Write "        if (t < Nt)"
        wrJS.Write "        {"
        wrJS.Write "            fn(t);"
        wrJS.Write "            t++;"
        wrJS.Write "            setTimeout(run, interval);"
        wrJS.Write "        }"
        wrJS.Write "        else"
        wrJS.Write "        {"
        wrJS.Write "            onComplete();"
        wrJS.Write "        }"
        wrJS.Write "    }"
        wrJS.Write "    run();"
        wrJS.Write "}"
\end{lstlisting}
1行目において、アニメーション生成における時間制御処理を行うrepeatSeq関数を定義している。本関数は四つの引数を取る。
第一引数は、各フレームごとに実行される処理を表す関数であり、フレーム番号tを引数として受け取る。第二引数は、処理の実行時間をミリ秒単位で指定するものであり、アニメーションの時間的な間隔を制御する。
第三引数は、処理を繰り返す回数を表し、アニメーションの総フレーム数に相当する。第四引数は、すべての繰り返し処理が終了した後に実行される空の関数である。
関数内部では、変数tを用いてフレーム番号を管理している。内部関数runにおいて、tがNt未満である場合は、fn(t)を実行する。その後setTimeoutを用いて一定時間後に再び呼び出すことで、処理を繰り返している。
tがNtに達した時点で繰り返し処理を終了し、onCompleteを実行することで、アニメーションを終了する。

\subsection{HTMLによる描画領域設定}\label{subsec:html}
ソースコード\ref{html_code}は、ソースコード\ref{animation_fs}内のSVGを用いたアニメーション描画領域を生成する処理を実装したコードである。
 \begin{lstlisting}[caption={描画領域設定},label={html_code},breaklines=true,breakatwhitespace=false]
        write ("<svg viewBox=\"0 0 "+s.sX.ToString()+" "+s.sY.ToString()+"\" ")
        write ("width=\""+s.sX.ToString()+"px\" ")
        write ("heigth=\""+s.sY.ToString()+"px\" ")
        write "xmlns=\"http://www.w3.org/2000/svg\" "
        write ("style=\"margin-left: "+s.mX.ToString()+"; ")
        write ("margin-top: "+s.mY.ToString()+"; ")
        write "position: absolute;"
        write ("background-color: "+s.backgroundColor+";")
        write "\">"
        code(f,p)
        write "</svg>"
\end{lstlisting}
1～3行目では、SVG要素を生成し、描画領域の大きさを設定している。5～8行目ではstyle属性を用いて、描画領域の配置位置および背景色を指定している。
9～11行目では、code関数によってSVG内部の描画内容を生成し、最終的にSVGタグを閉じることで描画領域を完成させている。

\section{ボタン効果}
\ref{subsec:startbuttom}節および\ref{subsec:resetbuttom}節では、\ref{sec:animation}節で説明したアニメーションボタンの位置を指定する第五引数の設定により生成されるコードについて説明する。
\ref{subsec:startbuttom}節ではstartボタンのソースコードとその動作について述べ、\ref{subsec:resetbuttom}節ではresetボタンのソースコードとその動作について説明する。
\subsection{startボタン}\label{subsec:startbuttom}
ソースコード\ref{startbuttom_html}はstartボタンを画面に表示するHTMLファイルであり、ソースコード\ref{startbuttom_js}はstartボタン押下時の処理を示すJavaScriptファイルである。
これら二つのソースコードは、アニメーション描画領域の生成時に自動生成される。
 \begin{lstlisting}[caption={startボタン（htmlファイル）},label={startbuttom_html},breaklines=true,breakatwhitespace=false]
</div>
<button id = "startButtonstart0" onclick = "animationStartMap['start0']()" style = "position: absolute; margin-left: 960px; margin-top: 450px; z-index: 1000;" >
Start
</button>
</div>
\end{lstlisting}
ソースコード\ref{startbuttom_html}では、buttom要素を用いてstartボタンを画面上に配置し、onclick属性によってボタン押下時にJavaScriptで定義されたアニメーション開始処理を呼び出している。
onclick属性では、animationStartMapに登録されたアニメーション識別子に対応する処理を呼び出している。また、position、margin-left、margin-topを指定することで、ボタンの表示位置を制御している。
 \begin{lstlisting}[caption={startボタン（JavaScriptファイル）},label={startbuttom_js},breaklines=true,breakatwhitespace=false]
const animationStartMap = {
start0: () => {
    repeatSeq(animationSeqID0, 6, 50, () => {
    });
},
test: () => {}
};
\end{lstlisting}
ソースコード\ref{startbuttom_js}では、start0に対応する処理としてrepeatseq関数を呼び出し、指定された時間間隔および回数でアニメーションを実行している。
start0に対応する処理では、repeatSeq関数を用いてアニメーションの時間制御を行っており、第一引数にはアニメーションの描画処理、第二引数には時間間隔、第三引数には繰り返し回数を指定している。
本コードでは、6msごとに50回フレームが切り替わることを表しており、全体で$30\,\mathrm{ms} \times 50\,\text{回} = 300\,\mathrm{ms}$のアニメーションとなる。


\subsection{resetボタン}\label{subsec:resetbuttom}
ソースコード\ref{resetbuttom_html}はresetボタンを画面に表示するHTMLファイルであり、ソースコード\ref{resetbuttom_js}はresetボタン押下時の処理を示すJavaScriptファイルである。
これら二つのソースコードは、アニメーション描画領域の生成時に自動生成される。
 \begin{lstlisting}[caption={resetボタン（HTMLファイル）},label={resetbuttom_html},breaklines=true,breakatwhitespace=false]
</div>
<button id = "resetButtonstart0" onclick = "animationResetMap['reset0']()" style = "position: absolute; margin-left: 960px; margin-top: 475px; z-index: 1000;" >
Reset
</button>
</div>
\end{lstlisting}
ソースコード\ref{resetbuttom_html}では、buttom要素を用いてresetボタンを画面上に配置し、onclick属性によってボタン押下時にJavaScriptで定義されたアニメーションのリセット処理を呼び出している。
ボタンの配置方法および表示位置の制御は、\ref{subsec:startbuttom}節で示したstartボタンの場合と同様であるため、ここでは省略する。
 \begin{lstlisting}[caption={resetボタン（JavaScriptファイル）},label={resetbuttom_js},breaklines=true,breakatwhitespace=false]
const animationResetMap = {
reset0: () => {
    animationSeqResetID0();
},
test: () => {}
};

function resetAll(){
    for (const key in animationResetMap) {
        if (typeof animationResetMap[key] === "function") {
            animationResetMap[key]();
        }
    }
}
\end{lstlisting}
ソースコード\ref{resetbuttom_js}では、各アニメーションをリセットする処理を示したコードである。
resetAll関数では、animationResetMapに登録されているすべてのリセット処理を順に実行している。これにより、複数のアニメーションを同時に初期状態へ戻すことが可能となる。

\subsection{生成と表示}
ソースコード\ref{AnimationLine}では、直線を描画するアニメーション処理を示したコードである。

and Line = {

    do
        html.taga ("line", [Atr("id",id);]@[s0.atr])
    member this.ID with get() = id
    member this.P (f:Line) = 
        let t = Var_e "t"
        wrJS.Write ("    var e = document.getElementById(\""+id+"\");")
        wrJS.Write ("    var x1 = " + (f.Start.X t).str JavaScript + ";")
        wrJS.Write ("    var y1 = " + (canvasY - f.Start.Y t).str JavaScript + ";")
        wrJS.Write ("    var x2 = " + (f.End.X t).str JavaScript + ";")
        wrJS.Write ("    var y2 = " + (canvasY - f.End.Y t).str JavaScript + ";")
        wrJS.Write ("    e.setAttribute(\"style\"," + "\"" + s1.code0 + "\");")
        wrJS.Write "    e.setAttribute(\"x1\", x1);"
        wrJS.Write "    e.setAttribute(\"y1\", y1);"
        wrJS.Write "    e.setAttribute(\"x2\", x2);"
        wrJS.Write "    e.setAttribute(\"y2\", y2);"
        
        wrJSAnimationSeqReset.Write ("    var e = document.getElementById(\""+id+"\");")
        wrJSAnimationSeqReset.Write ("    e.setAttribute(\"style\"," + "\"" + s0.code0 + "\");")
\end{lstlisting}
1～3行目では、直線の始点および終点の座標を表している。なお、StartおよびEndはtposition型で定義されており、二次空間上の位置を表す。
fsxファイルにおいて具体的な数値を与えることで直線の生成が可能となる。
\par
6行目では、s0はvisibilityがhiddenに設定されており、非表示状態を表す。7行目では、s1はvisibilityがvisibleに設定されており、表示状態を表す。
9行目に示すように、直線が生成された段階ではs0の状態になっている。その後、startボタンが押下されることで、18行目でにおいてs0からs1の状態へと切り替わる。
\par
また、resetボタンが押下されると、25行目に示すように初期状態であるs0の状態に戻る。このようにして図形の生成および表示制御を行っている。
